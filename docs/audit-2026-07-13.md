# Audit & Overhaul — 2026-07-13

Multi-agent audit (5 dimensions × adversarial verify) + live Playwright testing.
Consolidated, code-verified bug inventory driving the overhaul.

## Correctness / crashes
- **Crash-loop on bad config** — `drawnPicks + byRecordPicks > teamCount` ⇒ negative `lockedPicks` ⇒ `new Array(-n)` throws `Invalid array length` in `initStateFromConfig`. Persisted, so every reload crashes and the Reset button (bound inside the crashing `initApp`) is dead. *(Reproduced in browser.)*
- **`importConfig` under-validates** — only checks combinations sum; accepts missing/negative/mismatched fields, persists them, then crashes.
- **`runQuickLottery` infinite loop** — if fewer than `drawnPicks` teams have positive combinations (reachable via import with 0/negative combos), the `while(true)` draw loop never terminates → tab freeze.
- **`computeOdds` ignores `floorPicks`** — the shipped Fantasy Football preset sets `floorPicks: 2`; the simulation rejection-samples on the floor but the displayed odds table does not, so published odds ≠ actual lottery.
- **`computeOdds` exponential blow-up** — exact state enumeration freezes the UI for large drawn-pick counts (~6s at 20 teams / 14 drawn).
- **Reveal timer leak** — `closeModal` clears no `setTimeout`/`setInterval`; `showPickTimer` re-resolves the modal via a global `querySelector`, so a cancelled ceremony can resume inside a *new* modal and overwrite the new run's official result + history.
- **Close mid-ceremony discards the official result** — `lastLotteryResult`/history never committed if closed before `finishReveal`.
- **No re-entry guard on Run** — rapid double-click stacks two ceremonies.
- **State incoherence on league switch / reconfigure** — history, stale results, and locked team/ownership state leak between leagues; reconfigure that changes only `rounds`/`byRecordPicks` (or team *names* with unchanged structure) silently drops or reverts data while staying "locked".

## Layout robustness
- Podium CSS only defines `.pos-1..4` / `.place-1..4`; 5–6 drawn picks render unstyled.
- Podium positions snapshotted from a one-time `offsetLeft`; break on resize / wrap on mobile.

## Accessibility (WCAG)
- White text on gold/silver podium ≈ 1.4:1 contrast (1.4.3).
- Draft-format radios `display:none` — unreachable by keyboard/SR.
- Toasts are the sole error channel, auto-dismiss ~2.7s, no pause/dismiss (2.2.1); errors not mirrored inline.
- Focus escapes the `aria-modal` dialog after `innerHTML` wipes; no focus restoration on close (2.4.3).
- `prefers-reduced-motion` honored in CSS but ignored by the JS ceremony; no skip control.
- Fixed pick-timer covers the modal close button.
- Odds table not keyboard-scrollable; scroll hint only < 600px; toast `role="alert"` vs `aria-live="polite"` conflict.
- Toast entry keyframe leaves a stale `translateX(-50%)` → horizontal snap.

## UX friction (redesigned, not just patched)
- Wizard collects team names, then the main page forces re-confirming the *same* names.
- Pick ownership defaults to unset — 30 mandatory dropdowns before the lottery can run.
- Reconfigure wizard has no Cancel; Back discards the current step; magic-number 0/blank silently coerces to 1.

## Overhaul decisions
- **Remove `floorPicks`** entirely (niche, non-standard, sole source of odds/sim mismatch + redraw complexity).
- **Default pick ownership to self-owned** so the lottery is runnable immediately; trading is opt-in.
- **Drop the redundant confirm gates**; names/ownership edit inline and persist.
- Rebuild the reveal ceremony: single owner of all timers, clean cancel, Skip control, reduced-motion aware, robust for any drawn count, WCAG-compliant contrast + focus.
- Harden config load/import with full validation + a non-crashing recovery path.
- Per-league history; clear stale results/state on every league switch.
